# AI Use Log

AI tools were used during the PulseCart project mainly for coding assistance, debugging, and understanding technical concepts.

1. Used AI to help understand SQL queries for data extraction and validation.
2. Used AI to understand hypothesis testing, p-values.
3. Used AI to troubleshoot the churn prediction workflow and understand data leakage and time-based splitting.
4. Used AI for guidance while implementing K-Means, DBSCAN, and PCA.
5. Used AI to help with regex patterns for extracting order IDs, emails, and phone numbers from support messages.
6. Used AI for basic guidance on implementing the small CNN for image classification.

All code was run on the PulseCart dataset, and the results were checked in the notebook before being used in the final analysis.
